# 房総 通行止め自動回避ナビ（無料構成）

## 何をするものか
- GitHub Actions が10分ごとに国・千葉県・自治体の公式公開ページを自動巡回
- `docs/closures.json` を生成
- GitHub Pages の画面は5分ごとにそのJSONを再読込
- 位置を確定できた通行止めを地図表示し、openrouteservice の `avoid_polygons` で回避ルートを計算
- スタッフが通行止めを手入力する必要はありません

## 初回だけ必要なもの
1. GitHub の無料アカウント
2. このフォルダ一式を新しいリポジトリへアップロード
3. Repository Settings → Pages → Source を **GitHub Actions** にする
4. Actions を一度実行する（以後は10分ごとに自動）
5. ルート検索を使うPCで openrouteservice の無料APIキーを一度だけ保存

## 重要な仕様
公式サイトの文章だけでは位置を確定できない規制があります。その場合は一覧には表示しますが、誤った道路を避けないよう自動回避対象にはしません。

現在は国道127号の代表的な事前通行規制区間（元名〜金谷、南無谷〜小浦）を、道路管理者の公開資料に基づく既知区間として座標化しています。今後、房総の主要規制区間を同じ方法で増やすほど自動回避精度が上がります。

## 使用データ・サービス
- 国・自治体の公式公開道路情報
- OpenStreetMap（地図・場所検索）
- openrouteservice / HeiGIT（ルート計算、無料API枠）
